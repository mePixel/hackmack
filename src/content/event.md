# Website content

Edit the settings above to update the website. Keep the `---` lines and YAML indentation.

- `name`: event name in the heading, navigation, footer, and metadata. Also review name mentions in `about.description` and `closing.title`.
- `theme`: brand colors; keep hexadecimal colors in quotes.
- `heroImage` and `images`: main photographs, decorative backgrounds, and favicon.
- `logos`: partner logos (`d` is the default image, `h2` is the hover image).
- `benefits`, `features`, `people`, and `steps`: section text and images.
- `enabled`: show or hide optional sections. Set `venue: true` once the venue is confirmed to restore its section, links, and public venue details.

Put images in `public/assets/` and reference them as `/assets/your-image.jpg`. Update `images.venueAlt` when replacing the venue photo. Files named `mosaic-*` receive the brand tint; use another name for full-color photographs.

Save to update the local preview. Rebuild and deploy to update the published website. This explanatory text below the settings is not displayed on the site.
